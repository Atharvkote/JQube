GitHub OAuth Test Harness

Manual test client for /api/v1/auth and /api/v1/github. Nothing is sent anywhere except the base URL below.

0 · Server

Change the port if your SERVER_PORT differs. All requests below go to this base.

1 · Login not logged in

User must already be registered & verified (/api/v1/auth/register then /verify). The JWT is kept in memory only, never persisted.

2 · Connect GitHub

Calls GET /api/v1/github/connect. Complete the flow in the new tab, authorize on GitHub, then come back here and click Check profile below — GitHub will redirect the tab to your configured app.frontend-url, this test page won't auto-detect that.

3 · Profile

4 · Manual callback tester (edge cases)

Use this to test the failure paths: a tampered state, an expired one, a reused/garbage code, or missing params entirely. It opens the URL directly so you can watch the redirect land on ...?status=error instead of erroring out.
