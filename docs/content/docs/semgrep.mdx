# Semgrep

[Semgrep](https://semgrep.dev) is an open-source static analysis engine that JQube uses for vulnerability detection. It supports 25+ programming languages and comes with 2,000+ community and pro rules.

## What is Semgrep?

Semgrep (Semantic Grep) is a fast, lightweight SAST tool that:

- **Pattern matching** — Finds code patterns using a syntax similar to the target language
- **Cross-file analysis** — Tracks data flow across functions and files
- **Multi-language** — Supports Java, Python, JavaScript, Go, Ruby, and more
- **Low false positives** — Rules are written to be precise and actionable
- **Fast** — Typically scans 100K lines of code in under 30 seconds

## Configuration

### Default Configuration

By default, JQube uses Semgrep's `auto` configuration which includes:

```bash title="Terminal"
semgrep --config=auto --json /path/to/repo
```

### Custom Rules

You can add custom Semgrep rules by creating a `.semgrep.yml` file in your repository:

```yaml title=".semgrep.yml"
rules:
  - id: custom-sql-injection
    pattern: |
      String query = "SELECT * FROM " + $USER_INPUT;
    message: "Potential SQL injection via string concatenation"
    severity: ERROR
    languages: [java]
    metadata:
      cwe: ["CWE-89"]
      owasp: ["A03:2021"]
```

<Callout type="info">
Custom rules are automatically picked up during scans. Place `.semgrep.yml` at the root of your repository.
</Callout>

## Example Findings

### SQL Injection (CWE-89)

```java title="Vulnerable Code"
// ❌ SQL injection via string concatenation
String query = "SELECT * FROM users WHERE id = " + userId;
Statement stmt = connection.createStatement();
ResultSet rs = stmt.executeQuery(query);
```

```java title="Fixed Code"
// ✅ Parameterized query prevents SQL injection
String query = "SELECT * FROM users WHERE id = ?";
PreparedStatement stmt = connection.prepareStatement(query);
stmt.setLong(1, userId);
ResultSet rs = stmt.executeQuery();
```

### Hardcoded Secret (CWE-798)

```python title="Vulnerable Code"
# ❌ Hardcoded API key
API_KEY = "sk-1234567890abcdef"
```

```python title="Fixed Code"
# ✅ Environment variable
import os
API_KEY = os.environ.get("API_KEY")
```
