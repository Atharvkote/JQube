# Pull Requests

JQube automates the creation of GitHub Pull Requests for security fixes. After generating and reviewing an AI remediation, you can create a PR with a single click.

## PR Creation Flow

1. **Generate remediation** — AI creates a secure fix
2. **Review diff** — Compare original and fixed code
3. **Edit if needed** — Modify the fix in the editor
4. **Create PR** — JQube creates a branch, commits, and opens a PR

## Creating a Pull Request

```bash title="cURL"
curl -X POST http://localhost:8080/api/remediations/1/pull-request \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

## What JQube Does

Under the hood, JQube performs these GitHub API calls:

```java title="PullRequestService.java"
public PullRequest createPullRequest(Remediation remediation) {
    Finding finding = remediation.getFinding();
    Repository repo = finding.getRepository();
    String token = decryptToken(repo.getProject().getUser());

    // 1. Get the default branch SHA
    String baseSha = gitHubClient.getRef(repo.getFullName(), "main", token);

    // 2. Create a new branch
    String branchName = "jqube/fix-" + finding.getRuleId() + "-" + Instant.now().getEpochSecond();
    gitHubClient.createRef(repo.getFullName(), branchName, baseSha, token);

    // 3. Get current file content
    String currentContent = gitHubClient.getFileContent(
        repo.getFullName(), finding.getFilePath(), "main", token);

    // 4. Apply the fix
    String fixedContent = applyFix(currentContent, remediation);

    // 5. Commit the change
    gitHubClient.updateFile(repo.getFullName(), finding.getFilePath(),
        fixedContent, branchName, commitMessage, token);

    // 6. Create the Pull Request
    return gitHubClient.createPullRequest(
        repo.getFullName(), branchName, "main",
        prTitle, prBody, token);
}
```

## PR Template

Each auto-generated PR includes:

- **Title** — `fix: Resolve {vulnerability_type} ({cwe})`
- **Description** — Finding details, severity, and file location
- **Changes Summary** — What was changed and why
- **Labels** — `security`, `automated`, severity level
- **Attribution** — "Generated by JQube"

<Callout type="info">
Pull Requests are created using the user's GitHub token, so they appear as authored by the user.
</Callout>
