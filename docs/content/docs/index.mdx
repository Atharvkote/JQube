# Welcome to JQube

JQube is an **AI-powered DevSecOps platform** designed to integrate seamlessly into your development workflow. It connects to your GitHub repositories, performs deep security scanning using [Semgrep](https://semgrep.dev), detects vulnerabilities across 25+ programming languages, generates AI-powered secure remediations, and creates Pull Requests automatically.

<Callout type="info" title="Who is JQube for?">
JQube is built for **developers**, **security engineers**, **DevOps engineers**, **students**, and **open source contributors** who want to ship secure code without slowing down.
</Callout>

## Why JQube?

Traditional security scanning tools generate reports full of vulnerabilities but leave developers to figure out the fixes themselves. JQube closes this gap by not only detecting vulnerabilities but also **generating production-ready fixes** using AI.

### The Problem

- Security tools produce hundreds of findings with no actionable guidance
- Developers spend hours understanding and fixing each vulnerability
- Security reviews create bottlenecks in the development pipeline
- Manual code reviews miss subtle security issues

### The Solution

JQube automates the entire security remediation workflow:

1. **Connect** your GitHub repositories with OAuth
2. **Scan** your codebase with Semgrep's 2,000+ security rules
3. **Review** findings organized by severity (Critical, High, Medium, Low)
4. **Fix** vulnerabilities with AI-generated secure patches
5. **Ship** fixes via automated Pull Requests
