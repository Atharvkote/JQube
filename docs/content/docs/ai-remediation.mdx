# AI Remediation

JQube's AI Remediation engine uses large language models to generate **context-aware, secure code fixes** for every detected vulnerability. Instead of just reporting issues, it provides actionable solutions.

## How It Works

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   Finding    │────▶│  AI Engine   │────▶│  Secure Fix  │
│              │     │              │     │              │
│ • Rule ID    │     │ • Context    │     │ • Patched    │
│ • Code       │     │ • CWE Info   │     │   Code       │
│ • File Path  │     │ • Best       │     │ • Diff View  │
│ • Severity   │     │   Practices  │     │ • Commit Msg │
└──────────────┘     └──────────────┘     └──────────────┘
```

## Generating a Fix

```bash title="cURL"
curl -X POST http://localhost:8080/api/findings/1/remediate \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

```json title="Response — 200 OK"
{
  "id": 1,
  "findingId": 1,
  "originalCode": "String query = \"SELECT * FROM users WHERE id = \" + userId;\nStatement stmt = connection.createStatement();\nResultSet rs = stmt.executeQuery(query);",
  "fixedCode": "String query = \"SELECT * FROM users WHERE id = ?\";\nPreparedStatement stmt = connection.prepareStatement(query);\nstmt.setLong(1, userId);\nResultSet rs = stmt.executeQuery();",
  "explanation": "The original code constructs a SQL query using string concatenation with user-supplied input, making it vulnerable to SQL injection (CWE-89). The fix uses a PreparedStatement with parameterized queries, which prevents SQL injection by treating user input as data rather than executable SQL.",
  "confidence": 0.95,
  "model": "gpt-4",
  "createdAt": "2024-01-15T10:31:00Z"
}
```

## AI Prompt Engineering

The AI remediation engine constructs a carefully engineered prompt:

```text title="Prompt Template"
You are a senior security engineer. A static analysis tool (Semgrep) has
detected the following vulnerability:

Rule: {ruleId}
Severity: {severity}
CWE: {cwe}
Message: {message}

File: {filePath}
Language: {language}

Vulnerable code:
[code block of language]
{codeSnippet}
[end code block]

Provide a secure fix for this vulnerability. Requirements:
1. Fix ONLY the security issue
2. Preserve the original code's functionality
3. Follow {language} best practices
4. Use the most secure approach available
5. Do not change variable names or method signatures unnecessarily

Return ONLY the fixed code without explanations.
```

## Editing Fixes

Generated fixes can be edited in the built-in Monaco editor before creating a Pull Request:

1. Click **Generate Fix** on a finding
2. Review the AI-generated fix in the diff viewer
3. Click **Edit** to open the Monaco editor
4. Modify the fix as needed
5. Click **Save** to update the remediation
6. Click **Create PR** when satisfied

## Batch Remediation

Generate fixes for multiple findings at once:

```bash title="cURL"
curl -X POST http://localhost:8080/api/findings/remediate-batch \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "findingIds": [1, 2, 3, 4, 5],
    "priority": "CRITICAL_FIRST"
  }'
```

<Callout type="warning">
Batch remediation may take several minutes depending on the number of findings and the AI provider's rate limits.
</Callout>
