# Frontend Architecture

The JQube frontend is a modern single-page application built with React 18, TypeScript, and Tailwind CSS.

## Technology Stack

| Technology | Version | Purpose |
|---|---|---|
| **React** | 18.2 | UI component library |
| **TypeScript** | 5.3 | Type safety |
| **Tailwind CSS** | 3.4 | Utility-first styling |
| **Zustand** | 4.5 | State management |
| **React Router** | 6.22 | Client-side routing |
| **Monaco Editor** | 0.47 | Code editing |
| **Axios** | 1.6 | HTTP client |
| **React Query** | 5.0 | Server state caching |
| **Framer Motion** | 11.0 | Animations |

## Key Components

### Dashboard

The dashboard provides an overview of all projects, recent scans, and vulnerability trends:

- **ProjectList** — Grid of project cards with scan statistics
- **ScanHistory** — Timeline of recent scans with status indicators
- **VulnerabilityChart** — Severity distribution chart
- **QuickActions** — Buttons for common operations

### Code Editor

The Monaco Editor integration provides IDE-level code editing:

```typescript title="EditorWrapper.tsx"
import Editor from '@monaco-editor/react';

interface EditorProps {
  value: string;
  language: string;
  onChange: (value: string) => void;
  readOnly?: boolean;
}

export function CodeEditor({ value, language, onChange, readOnly }: EditorProps) {
  return (
    <Editor
      height="500px"
      language={language}
      value={value}
      onChange={(val) => onChange(val ?? '')}
      theme="vs-dark"
      options={{
        readOnly,
        minimap: { enabled: false },
        fontSize: 14,
        fontFamily: 'JetBrains Mono',
        lineNumbers: 'on',
        scrollBeyondLastLine: false,
        automaticLayout: true,
      }}
    />
  );
}
```

### Diff Viewer

Side-by-side comparison of original and fixed code:

```typescript title="DiffViewer.tsx"
import { DiffEditor } from '@monaco-editor/react';

interface DiffProps {
  original: string;
  modified: string;
  language: string;
}

export function DiffViewer({ original, modified, language }: DiffProps) {
  return (
    <DiffEditor
      height="500px"
      language={language}
      original={original}
      modified={modified}
      theme="vs-dark"
      options={{
        readOnly: true,
        renderSideBySide: true,
        fontFamily: 'JetBrains Mono',
      }}
    />
  );
}
```

## State Management

JQube uses Zustand for lightweight, scalable state management:

```typescript title="store/authStore.ts"
import { create } from 'zustand';

interface AuthState {
  user: User | null;
  token: string | null;
  isAuthenticated: boolean;
  login: (token: string, user: User) => void;
  logout: () => void;
}

export const useAuthStore = create<AuthState>((set) => ({
  user: null,
  token: null,
  isAuthenticated: false,
  login: (token, user) => set({ token, user, isAuthenticated: true }),
  logout: () => set({ token: null, user: null, isAuthenticated: false }),
}));
```

## API Service Layer

All API calls go through a centralized service layer:

```typescript title="services/api.ts"
import axios from 'axios';
import { useAuthStore } from '../store/authStore';

const api = axios.create({
  baseURL: import.meta.env.VITE_API_URL || 'http://localhost:8080/api',
  headers: { 'Content-Type': 'application/json' },
});

api.interceptors.request.use((config) => {
  const token = useAuthStore.getState().token;
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

export default api;
```
